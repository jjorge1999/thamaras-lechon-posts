# Thamara's Lechon — daily post graphics

Images in `posts/` are generated by `make_post.py` (Claude-designed, no prices) and published to the
Thamara's Letchon Facebook Page through Buffer by a daily scheduled task.

    python3 make_post.py spec.json posts/YYYY-MM-DD-slug.jpg

Styles: `lechon`, `lechon_sliced`, `karenderia`, `bbq`, `poll`. See the docstring in `make_post.py`.
Base photos live in `assets/`.
